# Reseller Profit Analyzer

A Python desktop application that helps online resellers calculate and track profit from individual sales.

## Screenshot

![Reseller Profit Analyzer application](screenshot.png)

## Features

- Calculates platform fees
- Calculates net profit and profit margin
- Validates user input
- Saves sales to a CSV file
- Displays a summary of saved sales
- Prevents accidental duplicate saves
- Clears the form after saving

## Technologies

- Python
- Tkinter
- CSV data storage

## How to Run

1. Install Python 3.
2. Download the project files.
3. Run:

```bash
python app.py
